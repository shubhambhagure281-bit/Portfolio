I’m a B.Sc. Computer Science student and Android Application Developer with a strong interest in building practical, user-friendly mobile apps.

My project work includes native Android applications built with Java and structured XML layouts, with Firebase Cloud Services and MySQL used in application projects. I also develop web applications and enjoy bringing mobile and web experiences together when a project needs both.

A key example is Gram Panchayat Jambhai: I developed an Android application connected with its web platform. The citizen portal brings village information and services together, including Panchayat and officials’ details, citizen certificates, complaint registration and tracking, notices, government schemes, and contact and emergency information.

Working on real applications has helped me practise interface development, app and web integration, API/backend and database integration, and problem solving. I care about making the experience clear and responsive, and about connecting the pieces into something useful for people.
